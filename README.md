# 🩸 Blood Donation Analytics System

A **Flask-based web application** that helps manage **blood donors and inventory**, with **real-time analytics and visualizations** using **Chart.js** and **SQLite**.

## 🚀 Features

- Donor Registration & Management  
- Blood Inventory Tracking  
- Real-Time Charts & Visual Dashboards  
- Built with Flask, HTML/CSS, Chart.js, and SQLite

## 📊 Tech Stack

- Python (Flask)  
- SQLite  
- Chart.js  
- HTML & CSS
